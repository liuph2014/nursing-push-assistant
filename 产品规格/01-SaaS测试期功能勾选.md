# SaaS 测试期功能勾选确认

- 日期：2026-09-20
- 产品：护理推送助手
- 依据：功能目录计划（先 SaaS 测试、后小程序）
- 决策：计划确认时未另勾加减项，**本期范围 = 建议测试包**。P1 / 后置 / 慎选一律不进开发，只在本文登记去向。

## 1. 本期要证明的故事

护士长建入院/出院路径 → 责任护士套到床位 → 患者扫床头码或打开 H5 → 阅读计入已读/未读 → 未读进入护士待办 → 护理部看覆盖率。

不接 HIS、不做微信小程序、不开直播/患友会/培训考试，也能把闭环跑通。

```mermaid

  accTitle: SaaS测试期闭环
  accDescr: 从路径配置到护理部看覆盖率的最小可演示链路

  Read --> Todo[未读待办]
  Todo --> Board[护理部看板]
```

## 6. 验收口径（测试期过关条件）

1. 护士长能启用一条「入院第 0 天 + 出院当天」路径。
2. 责任护士把路径套到至少 1 张责任床，床头码可打开 H5。
3. 患者在 H5 读完一篇文章后，护士端该条变为已读，并记下停留时长。
4. 未读患者出现在「今日任务」。
5. 护理部（或只读质控）能按科室看到覆盖率并导出。
6. 审计能查出「谁、何时、对哪位患者、推了哪篇」。
7. 另一租户的数据在界面与导出中均不可见。
