# 护理推送垂直切片 Demo · 演示路径说明书

**用途：** 现场或电脑上按路径走通「入院宣教作业闭环」，并可按勾选表演示标记组、群发、计划、问卷与质控占位。  
**对象：** 护士长 / 责任护士 / 护理部演示讲解；研发自测。  
**对应代码：** `护理推送助手/code`  
**口径：** 这是演示版，不是完整 SaaS。纳入 59 项里，能点开讲解的都做成了种子+薄界面；小程序、订阅消息、HIS、咨询、短信不做。

---

## 1. 演示在验证什么

主路径（约 15 分钟）仍是一条护士站作业闭环：

1. 护士长给 **1 床** 套用「普通入院」路径  
2. 患者用微信扫床头码（或电脑打开 H5）同意进入  
3. 读完 **入院须知**（停留满 8 秒）→ 护士端记为已读  
4. **故意不读**「防跌倒宣教」→ 出现在「当面补讲」  
5. 护士点「已当面完成」  
6. 护理部看板数字能对上刚才的操作  
7. 责任护士只能操作责任床（默认 1–4 床，护士长可改分床）

支线（按需加 5–10 分钟）：

8. 床位详情勾选 **标记组**（目录由护士长在设置里维护），床位图出现色点  
9. **群发**：从图文库卡片选文，按标记组筛人，立即发送或「明天」+ 演示条快进  
10. **计划**：高危跌倒 × 首次扫码当日；4 床扫码后点「执行到期任务」会补防跌倒（若尚未套路径）  
11. 护士长在「路径」启用 **脑梗死路径** 后，可套到患者；+1 天条目进「待推」，快进一天后投递  
12. 看板看成员覆盖率、24 小时路径完成率、月报打印；设置里开入科表单 / 全科确认闸门

**明确不做工程：** 微信小程序、订阅消息、短信、HIS、屏厂 SDK、咨询模块、真实验证码网关。07.6 只出与 H5 同一条「屏用大字码」。授权页仍是「同意并进入」。

## 2. 开始前准备

### 2.1 电脑端（必做）

1. 进入目录 `护理推送助手/code`  
2. 执行：

```bash
npm install
npm run dev
```

3. 浏览器打开 <http://localhost:3000>，应自动进入 **床位图**。  
4. 顶部有深蓝色 **演示条**。没有演示条或一直白屏：结束占用 3000 端口的旧 `node` 进程后重跑 `npm run dev`，浏览器 **Ctrl+F5** 强制刷新。  
5. 若刚升级过数据结构，请点演示条 **重置演示数据**（点两次），或删掉本机 PGlite 目录后重启。

### 2.2 微信真机扫码（可选，公网 HTTPS）

本地 `http://localhost:3000` 的二维码在微信里通常打不开。真机扫码需部署到 Vercel（HTTPS），并配置：

| 环境变量 | 含义 |
| --- | --- |
| `DATABASE_URL` | Neon Postgres 连接串 |
| `NEXT_PUBLIC_APP_URL` | `https://你的项目.vercel.app`（不要斜杠结尾） |

改完 `NEXT_PUBLIC_APP_URL` 后必须重新部署，床头码才会指向公网域名。电脑验收可全程用演示条 **「打开该床患者 H5」**，不必等微信。

### 2.3 预置数据（重置后应恢复）

| 项 | 内容 |
| --- | --- |
| 病区 | 1 个演示病区，8 张床（另有内部空床用于转床） |
| 患者假名 | 1–8 床：张一、李二、王三、赵四、钱五、孙六、周七、吴八 |
| 护理档案 | 姓名、性别、年龄、住院号 `demo-00N`、入科日、诊断、护理等级、饮食医嘱、过敏史、手术日、联系人电话 |
| 标记组 | 病种-脑梗死、手术、高危跌倒、糖尿病饮食（各床已预打不同组合；护士长可在设置里增删改） |
| 路径 | 「普通入院」已启用：入院须知 + 防跌倒。「脑梗死路径」待审核：饮食 + 满意度问卷 + 次日康复 |
| 计划 | 高危跌倒 · 首次扫码当日 · 防跌倒 |
| 有效阅读 | 页面停留累计 **≥ 8 秒**（每 2 秒心跳一次） |
| 账号 | 可用演示条切角色，或打开 `/app/login` 假登录；邀请链接在「设置」 |
| 患者链接 | 1 床固定为 `/p/demo-bed-1-token`（重置后仍是这个码，可反复用） |

**责任护士分管：** 默认 1–4 床，护士长可在床位档案勾选改分。**护士长可操作：** 在院未淡显的床。**护理部 / 只读质控：** 看板与设置只读。

## 3. 演示条怎么用（医护端常驻）

仅医护电脑有演示条。患者 H5 **没有**演示条，页脚只有小字「演示数据」。

从左到右：

| 控件 | 作用 |
| --- | --- |
| 护士长 / 责任护士 / 护理部 / 只读质控 | 一键切角色，无需登录。切护理部或质控会跳到看板 |
| 当前床 1–8 | 切换后打开该床页；「打开该床患者 H5」跟这张床走 |
| 打开该床患者 H5 | 新标签打开患者页（电脑预览用） |
| 复制患者链接 | 手机扫不开码时的兜底 |
| 快进一天 | 演示时钟 +1 天，并自动执行到期任务（定时群发、待推、计划、自动出院） |
| 执行到期任务 | 不改日期，只跑调度 |
| 步骤 1–9 | 跳到对应页，主按钮橙色描边高亮 |
| 重置演示数据 | **必须点两次**才真正重置；只清演示租户 |

建议顺序：护士长套 1 床路径 → 读入院须知满 8 秒 → 不读防跌倒 → 当面补讲完成 → 护理部看板。标记组 / 群发用步骤 8、9。

每轮演示开始前：点「重置演示数据」→ 按钮变成橙色「再点一次确认重置」→ 再点一次。8 秒内不点第二次会取消。重置后应看到 8 床、均未套路径、待学习为空、标记色点仍在。

## 4. 主路径（必须全过）

全程约 15–20 分钟。电脑用 Chrome；患者侧可用第二个浏览器窗口代替微信。

### 步骤 0 · 确认入口

- [ ] 打开 <http://localhost:3000>（或 Vercel 地址）进入床位图  
- [ ] 顶部有演示条，能看到 8 张床卡和标记色点  
- [ ] **无需注册、验证码、下载 App**（登录页为演示入口，可跳过）

### 步骤 1 · 护士长套路径

1. 演示条点 **护士长**  
2. 点步骤 **「1 套路径」**（应进入 1 床，橙色框住「套用入院路径」）  
3. 点橙色大按钮 **套用入院路径**（默认普通入院）

**通过标准：**

- [ ] 文案变为已套用路径  
- [ ] 列表出现两篇：**入院须知 未读**、**防跌倒宣教 未读**  
- [ ] 右侧床头码可见，下方地址为 `…/p/demo-bed-1-token`  
- [ ] 演示条「打开该床患者 H5」指向同一 token（同一条链接）  
- [ ] 下方能看到 **标记组** 分区（1 床预打脑梗死、高危跌倒）

### 步骤 2 · 患者同意并看到待学习

**电脑：** 演示条点「打开该床患者 H5」。  
**微信（已部署 HTTPS）：** 扫 1 床二维码。

1. 进入「健康教育知情提示」  
2. 点满宽按钮 **同意并进入**

**通过标准：**

- [ ] 患者页没有医护演示条  
- [ ] 页脚有「演示数据」  
- [ ] 「我的待学习」出现两篇，状态为待学习  
- [ ] 未要求注册 / 验证码 / 下载 App

### 步骤 3 · 只读文章 A（入院须知）

1. 打开 **入院须知**  
2. 顶部会出现「请停留阅读，大约还有 N 秒记为已读」  
3. **停留满 8 秒**，直到变成「已记为有效阅读，可返回待学习」  
4. **不要打开**「防跌倒宣教」（或打开后立刻返回，停留不够 8 秒）

回到护士电脑 1 床页（或点步骤「4 看已读」），等待约 3 秒自动刷新。

**通过标准：**

- [ ] 护士端「入院须知」变为 **已读**（绿色），可看到停留秒数  
- [ ] 「防跌倒宣教」仍为 **未读**（红色）  
- [ ] 床位图 1 床可出现未读红点（防跌倒未读）

### 步骤 4 · 当面补讲

1. 点步骤 **「5 当面补讲」**，或导航 **今日任务 → 当面补讲**  
2. 应看到：**1 床 张一 · 防跌倒宣教**  
3. 点 **已当面完成**

**通过标准：**

- [ ] 点完后该条离开「当面补讲」Tab（栏内暂时没有任务）  
- [ ] 回到 1 床页，「防跌倒宣教」变为 **已当面完成**

### 步骤 5 · 护理部看板

1. 演示条点 **护理部**（会进看板），或点步骤「7 看板」  
2. 对照数字（在刚走完主路径、尚未再次重置时）：

| 指标 | 刚重置后 | 走完主路径后 |
| --- | ---: | ---: |
| 今日新增 | 0 | **1**（套了路径的人数） |
| 有效阅读人数 | 0 | **1**（读过入院须知或已补讲的 1 床） |
| 未读人数 | 0 | **0**（防跌倒已当面完成） |
| 在院人数 | 8 | **8** |

**通过标准：**

- [ ] 身份显示为护理部，姓名脱敏为「张*」  
- [ ] 「今日新增」「有效阅读人数」与重置后不同，且能对上刚才 1 床的操作  
- [ ] 护理部进入 1 床应提示不能套路径（只读）  
- [ ] 能看到成员数据、24 小时完成率、月报打印

### 步骤 6 · 责任护士权限

1. 演示条点 **责任护士**  
2. 打开 **床位**

**通过标准：**

- [ ] 副标题写仅可操作责任床  
- [ ] 5–8 床卡片变淡，并标注「非责任床」（若护士长未改分床）  
- [ ] 进入 **5 床**：无套路径按钮  
- [ ] 进入 **1 床**：仍可看到套路径按钮

### 步骤 7 · 演示步骤跳转

点演示条 **1–9**，每一跳都应到对应页。

| 步骤 | 应到达 | 应高亮 |
| --- | --- | --- |
| 1 套路径 | 1 床详情 | 「套用入院路径」 |
| 2 看床头码 / 3 读文章A | 1 床详情 | 右侧二维码区域 |
| 4 看已读 | 1 床详情 | 待学习列表 |
| 5 当面补讲 / 6 点完成 | 今日任务 · 当面补讲 | 「已当面完成」（有任务时） |
| 7 看板 | 科室看板 | 四张数字卡片 |
| 8 打标记 | 1 床标记组 | 标记组色块 |
| 9 群发 | 群发页 | 图文库卡片 / 发送 |

- [ ] 步骤可点击跳转，无需找隐藏菜单

## 5. 支线（纳入功能补全，可按场次选做）

### 5.0 护理作业台：档案、检索、标记组目录、图文库

1. **护士长**打开 1 床，改核心档案（如住院号、诊断、护理等级）后点「保存档案」；床位图检索框输入 `demo-001` 或「脑梗死」应能筛到 1 床  
2. **设置 → 标记组管理**：新增「吞咽障碍」，再到 1 床打上，床卡出现新色点；删除未被计划占用的组应成功。删除「高危跌倒」应提示先改计划  
3. **图文**页：护士长用小红书式编辑器发纯文字或图文，点红色「发布」；责任护士在右侧笔记库搜索后点「分发给患者」进入群发  
4. 切 **责任护士**：图文页没有发布器，不能改库；能搜索本科笔记并点「分发给患者」；设置里标记组不能删除  
5. 重置后 8 床档案（含 1 床男、68 岁、demo-001、一级护理、低盐饮食、青霉素过敏）与 4 个种子标记组仍在

**通过标准：** 床卡次行露出诊断或住院号；群发主按钮仍是橙色「发送」；选文区在筛人上方。

### 5.1 标记组 → 群发

1. 1 床标记组可勾选/取消（病种、手术、高危跌倒、糖尿病饮食）  
2. 打开 **群发**，从图文库点选《糖尿病饮食指导》，标记组选「糖尿病饮食」，范围「仅责任床」，点橙色「发送」  
3. 2 床（预打糖尿病饮食、且为责任床）待学习应出现该文

**通过标准：** 责任护士选「全科」被拒（设置未开确认闸门时）。发送记录有应发人数。

### 5.2 计划圈人

1. 不要给 **4 床** 套路径  
2. 打开 4 床患者 H5，同意进入（记首次扫码）  
3. 演示条点 **执行到期任务**  
4. 4 床应出现计划生成的「防跌倒宣教」（4 床预打高危跌倒）

若 1 床已套入院路径，计划不会重复推同一篇防跌倒。

### 5.3 病种路径、待推、问卷

1. **路径**页：护士长把「脑梗死路径」点「审核并启用」  
2. 给 1 床或 5 床套该路径：当日饮食文章 + 满意度问卷为已推；康复要点为 **待推**  
3. 快进一天后，待推变为已推未读  
4. 患者 H5 可答问卷，交卷显示等级；护士端 **问卷** 可导出 CSV  
5. **问卷**：护士长可在「问卷」页用问卷星式编辑器出题（含答案），勾选责任护士一键发送（不含答案）；责任护士在同页「答题通知」作答，自动判卷后双方都能看到原始作答、参考答案与分值；护士长看全部历次评分，责任护士只看自己的

### 5.4 转床出院、入科表单、屏用码

1. 床位详情可 **办理出院**（在院人数减 1）；再把在院患者 **转到** 已出院空床  
2. **设置**打开「扫码后先填联系人」，用 **2 床** H5：同意后须填联系人才能进宣教中心  
3. 床位详情下方「屏用大字码」与床头码同一 URL

### 5.5 设置闸门与审计

1. 打开「全科群发须护士长确认」后，责任护士可选全科，生成待确认，护士长确认或驳回  
2. **设置**页可看组织树、邀请链接、操作审计  
3. `/app/login?invite=demo-invite-neurology` 为假登录/邀请入口

## 6. 失败态（必须有，避免现场卡死）

### 6.1 码已失效

电脑打开：`http://localhost:3000/p/not-a-token`

- [ ] 明确写 **「码已失效，请找护士」**  
- [ ] 不会白屏、不会跳登录

### 6.2 未套路径就扫码

对 **2 床**（不要套路径）：演示条选 2 床 →「打开该床患者 H5」→ 同意并进入。

- [ ] 能进「我的待学习」  
- [ ] 列表为空（除非设置打开入科表单）  
- [ ] 提示大意：**还没有宣教任务，请让护士套用入院路径后再扫码**

### 6.3 重置不误伤

- [ ] 第一次点「重置演示数据」只变确认，数据不变  
- [ ] 第二次才清空并回到床位图  
- [ ] 重置后仍是 8 床、标记组、token 仍为 `demo-bed-N-token`

## 9. 现场讲解口径（约 3 分钟）

> 护士站先给床位套入院路径，床头码给患者。患者同意后读必读篇，系统按停留时间记有效阅读。没读的进「当面补讲」，护士床旁讲完一点就闭环。需要精准推送时，用标记组圈人，再群发或设计划，不必每人点一次发送。护理部看板看覆盖和 24 小时路径完成率。这一版用来把作业闭环和勾选功能讲清楚，不是完整健康教育中台，也不做小程序。

讲解时建议双屏：左护士站、右患者 H5。
